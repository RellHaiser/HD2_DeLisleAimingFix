# De Lisle Aiming Fix by RellHaiser 

## Description
This mod fixes the aiming bug for the De Lisle when firing while aimed. The aiming bug occurs after firing a shot aimed. Once the De Lisle's iron sights settle again, they are no longer aligned with the center of the screen where the shot originates.

https://youtu.be/Mmsym2Zwk5k?si=24x53wfFg6G9mqIi
